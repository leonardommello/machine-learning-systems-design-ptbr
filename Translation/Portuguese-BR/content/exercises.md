# Exercícios

As respostas dessas questões serão publicadas no livro **Machine Learning Interviews**. Você pode consultar as respostas da comunidade a essas questões, e contribuir com as suas, no GitHub [aqui](https://github.com/chiphuyen/machine-learning-systems-design/tree/master/answers). Leia mais sobre o livro e inscreva-se na lista de e-mails dele [aqui](https://huyenchip.com/2019/07/21/machine-learning-interviews.html).

Nota: muitas questões são ambíguas de propósito. Cabe a você, como candidato, pedir esclarecimentos e delimitar o escopo do problema.
 
1. O Duolingo é uma plataforma de aprendizado de idiomas. Quando um estudante está aprendendo um novo idioma, o Duolingo quer recomendar histórias de leitura cada vez mais difíceis.
	- Como você mediria o nível de dificuldade de uma história?
	- Dada uma história, como você a editaria para torná-la mais fácil ou mais difícil?
1. Dado um conjunto de dados com informações de compras com cartão de crédito, em que cada registro é rotulado como fraudulento ou seguro, como você construiria um algoritmo de detecção de fraude?
1. Você administra um site de comércio eletrônico. Às vezes, os usuários querem comprar um item que não está mais disponível. Construa um sistema de recomendação para sugerir itens substitutos.
1. Para qualquer usuário do Twitter, como você sugeriria quem ele deveria seguir? O que você faz quando esse usuário é novo? Quais são algumas das limitações dos sistemas de recomendação orientados a dados?
1. Quando você digita uma consulta de busca no Google, aparece uma lista de buscas relacionadas. Como você geraria uma lista de buscas relacionadas para cada consulta?
1. Construa um sistema que retorne imagens associadas a uma consulta, como no Google Images.
1. Como você construiria um sistema para sugerir hashtags em alta no Twitter?
1. Cada pergunta no Quora costuma receber muitas respostas diferentes. Como você cria um modelo que ordena todas essas respostas? Quão intensivo em computação é esse modelo?
1. Como você constrói um sistema para exibir os 10 primeiros resultados quando um usuário busca anúncios de aluguel em determinada localidade no Airbnb?
1. Autocompletar: como você construiria um algoritmo para terminar sua frase enquanto você escreve uma mensagem?
1. Quando você digita uma pergunta no StackOverflow, aparece uma lista de perguntas semelhantes para garantir que a sua ainda não tenha sido feita. Como você constrói um sistema desses?
1. Como você projetaria um algoritmo para agrupar passageiros de caronas compartilhadas na Lyft ou na Uber?
1. Em redes sociais como o Facebook, os usuários podem informar em que escola de ensino médio estudaram. Você consegue estimar que porcentagem das escolas listadas no Facebook é real? Como descobrimos, e implantamos em escala, uma forma de encontrar escolas inválidas?
1. Como você construiria um algoritmo de detecção de palavra de ativação para identificar a palavra "activate" em um trecho de áudio de 10 segundos?
1. Se você fosse construir um clone da Netflix, como construiria um sistema que prevê, quando um usuário para de assistir a uma série, se ele se cansou dela ou se está apenas fazendo uma pausa?
1. O Facebook gostaria de desenvolver uma forma de estimar o mês e o dia do aniversário das pessoas, independentemente de elas darem essa informação diretamente. Que métodos você proporia, e que dados usaria, para ajudar nessa tarefa?
1. Construa um sistema para prever o idioma em que um texto foi escrito.
1. Preveja o preço de um imóvel anunciado no Zillow. Use esse sistema para prever se devemos investir na compra de mais imóveis em determinada cidade.
1. Imagine que você trabalha no iPhone. Toda vez que os usuários desbloqueiam o telefone, você quer sugerir um aplicativo que eles tenham a maior probabilidade de abrir primeiro, com 90% de acurácia. Como você faria isso?
1. Como você mapeia apelidos (Pete, Andy, Nick, Rob etc.) para nomes reais?
1. Uma empresa de comércio eletrônico está tentando minimizar o tempo que os clientes levam para comprar os itens selecionados. Como engenheiro de aprendizado de máquina, o que você pode fazer para ajudá-la?
1. Construa um chatbot para ajudar as pessoas a reservar hotéis.
1. Como você projetaria um sistema de resposta a perguntas capaz de extrair uma resposta de uma grande coleção de documentos, dada uma consulta do usuário?
1. Como você treinaria um modelo para prever se a palavra "jaguar" em uma frase se refere ao animal ou ao carro?
1. Suponha que você esteja construindo um software para gerenciar a carteira de ações dos seus clientes. Você administra a quantia X. Imagine que converteu todo esse valor em ações e encontrou uma ação que definitivamente precisa comprar. Como você decide de qual das ações que já possui deve se desfazer para conseguir comprar essa nova ação?
1. Como você criaria um modelo para reconhecer se uma imagem é um triângulo, um círculo ou um quadrado?
1. Dado apenas o conjunto de dados CIFAR-10, como construir um modelo para reconhecer se uma imagem pertence ou não às 10 classes do CIFAR-10?
